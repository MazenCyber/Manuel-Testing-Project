# AutomationExercise – QA Testing Project

## 📌 Project Overview

This project is a practical Software Testing project performed on the **AutomationExercise** e-commerce web application.

The purpose of this project is to demonstrate practical skills in **Manual Testing, Test Case Design, Test Execution, Defect Reporting, and Test Documentation**.

**Application:** AutomationExercise
**Testing Type:** Functional Testing
**Project Type:** E-commerce Web Application
**Role:** QA Tester

---

## 🎯 Testing Objectives

The main objectives of this project are:

* Verify that the main e-commerce functionalities work as expected.
* Identify and document defects.
* Create clear and reusable test cases.
* Execute test cases and record their results.
* Verify the shopping and checkout flow.
* Prepare professional QA documentation.
* Practice real-world software testing activities.

---

## 📊 Test Execution

Test cases are classified using the following statuses:

| Status         | Description                                                               |
| -------------- | ------------------------------------------------------------------------- |
| ✅ Pass         | Actual result matches the expected result.                                |
| ❌ Failed       | Actual result does not match the expected result.                         |
| ⚠️ Blocked     | Test execution cannot continue because of a blocking issue or dependency. |
| ⏳ Not Executed | Test case has not yet been executed.                                      |

The Test Execution section contains the execution results and a graphical summary of the test status.
